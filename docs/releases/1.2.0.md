# Tellygram v1.2.0

This release is all about the photo viewer.

## In this release

- Full-screen photo preview, with a thumbnail strip along the bottom to step
  forward and back between photos
- Crop a photo to 1:1 / 4:3 / 16:9 (cover), or return it to its original ratio
- Rotate a photo by 0° / 90° / 180° / 270°
