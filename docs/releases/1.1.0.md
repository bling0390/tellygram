This release is mainly a UI rework: the chat screen and the settings screen are rebuilt to the new design, while the remaining screens are still being adjusted.

## In this release

- **UI rework**: the chat screen and the settings screen are rebuilt
- **Chat types**: private chats, groups and channels are all shown
- **Long-press actions**: Pin / Unpin, Mute / Unmute, Archive / Unarchive, Delete / Delete and leave (destructive actions ask for confirmation first)
- **Media types**: messages can be browsed by Video / Audio / Image / Text

## Still being adjusted

- The video player screen, the search screen and the QR login screen
- **Search**: the menu entry exists, but the interaction is still being designed
- **Settings**: currently Check for updates / Language / Log out; more is coming

## Known issues

- Audio messages in chats have not been playback-tested yet
